# Third-party notices

## ESPHome

The YAML configuration uses [ESPHome](https://github.com/esphome/esphome), including its Waveshare display, native API and font components. ESPHome is a separate upstream project and is not bundled in this repository.

## Inter

The configuration downloads the [Inter font](https://github.com/rsms/inter) through Google Fonts during an ESPHome build. Inter retains its upstream SIL Open Font License. The font is not committed to this repository.

## Material Design Icons

The configuration uses glyphs from [Pictogrammers / Material Design Icons](https://github.com/Templarian/MaterialDesign-Webfont/tree/v7.4.47). The download script retrieves version 7.4.47 and its [upstream license](https://github.com/Templarian/MaterialDesign-Webfont/blob/v7.4.47/LICENSE). The downloaded font and license remain together in the local `esphome/fonts` directory and are not committed here.
